# FrameUI store template

A standalone Angular application for day-to-day store operations. It includes:

- Overview
- Product catalog
- Inventory
- Orders and fulfillment
- Suppliers and purchase orders

Each feature folder contains its page, data, styles, and supporting components. Shared navigation
and local audit state live in `shared/`.

## Run the application

```bash
npm install
npm start
```

Open `http://localhost:4200/templates/store/overview`.

Inside the FrameUI monorepo, run:

```bash
npm run start:template-store
```
