# FrameUI administration template

A standalone Angular application for access and organization administration. It includes:

- User management
- Roles and permissions
- Audit log
- Settings

Each feature folder contains its page, data, styles, and supporting components. Shared navigation
and audit state live in `shared/`.

## Run the application

```bash
npm install
npm start
```

Open `http://localhost:4200/templates/administration/user-management`.

Inside the FrameUI monorepo, run:

```bash
npm run start:template-administration
```
